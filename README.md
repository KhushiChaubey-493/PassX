# 🔐 PassX Password Manager

A browser-based password management application built with **HTML, CSS, and JavaScript** for storing and managing credentials using browser Local Storage.

## 📌 Overview

PassX is a frontend project created to practice **CRUD operations, JavaScript, DOM manipulation, and browser-based data persistence**.

The application allows users to manage stored credential information directly within the browser.

> **Security note:** This project is intended as a learning project. Credentials stored in browser Local Storage should not be considered secure storage for real-world sensitive passwords.

## ✨ Features

* Add credential information
* View stored credentials
* Update credential information
* Delete stored credentials
* Persist data using Local Storage
* Browser-based interface

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript (ES6+)
* Local Storage
* DOM Manipulation

## ⚙️ How It Works

1. The user enters credential information.
2. JavaScript processes the submitted data.
3. The information is stored in the browser's Local Storage.
4. Stored records can be retrieved and displayed.
5. Users can update or delete existing records.
